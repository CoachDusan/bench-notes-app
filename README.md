# Bench Notes

A small offline web app for taking courtside observation notes.

Pick a player, pick the situation, write down what he actually did.
Notes are stored in your own browser on your own device — they are never
sent anywhere, and this repository contains no data of any kind.

Add it to your home screen and it works with no signal.

This repository holds only the published app. Save a backup file
regularly: browsers can and do clear their own storage.
